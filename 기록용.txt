ServerGetData
	- 서버로 부터 데이터를 호출 (1초마다)
	- 데이터를 처리
	- UI 변경이 필요한 데이터 선별-> MainWindowViewModel로 전달
	- NettyAsyncMsgProcess부터 오는 데이터를 처리 

	ServerGetData 에서 
		while (true) 
		{
			서버에 접속 -> 한번만
			if(서버와 접속상태 확인) 
			{
				서버와 재연결
			}
		
			고정적으로 서버로 부터 데이터를 받음 (1초 마다) -> 객체화 -> 리스트에 넣음
			데이터를 처리
			데이터를 UI에 변경 -> MainWindowViewModel로 전달 
		}

NettyAsyncMsgProcess
	- 서버로 부터 비동기적으로 데이터를 받음 (경매 진행중이나 카운트 다운 등... 경매프로그램에서 동작되는 버튼등의 액션을 쏴준다.)
	- 데이터를 처리 (일괄 , 단일 경매방식의 따라 처리방식이 약간 다릅니다.)
	- ServerGetData으로 데이터 전달 처리 
	  (왜냐하면 NettyAsyncMsgProcess부터 오는 데이터는 되게 간소화된 정보를 송신, 예를 들면 경매번호 3번 250만원에 낙찰 이렇게 온다고 생각하면 됩니다. 낙찰자명 등이 없음, 
	  전체적인 정보는 ServerGetData에서 가지고 있음 )
