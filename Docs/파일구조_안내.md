# CowAuctionSmall 파일 구조 안내

WPF·MVVM과 기존 해상도·사업장별 화면을 유지하며 책임별로 소스를 배치한다. 제품은 `CowAuctionSmall.csproj`를 사용하고, 독립 점검 도구는 `Tools/GAMSTest/GAMSTest.csproj`에서 제품 화면을 참조한다. 구조 개편의 구현·검증 결과는 [WORKLOG](../WORKLOG.md), 작업 기준은 [개편 계획](계획/완료/절충형_파일구조_개편계획_2026-09-17.md)을 참고한다.

## 2026-10-01 명칭 변경

`Infrastructure`를 `Infra`로, 내부 `Configuration`을 `XmlSettings`로 변경했다. 네임스페이스도 `CowAuctionSmall.Infra.*`와 `CowAuctionSmall.Infra.XmlSettings`로 통일했다. 기능과 내부 파일명은 유지한다. 이전 WORKLOG·계획의 경로 표기는 당시 이력이며 아래 담당 경로와 문서 링크가 현재 위치다.

## 어디를 수정할지

| 위치 | 담당 책임 |
|---|---|
| Domain/Auction | 개체 데이터·경매 상태·계류대별 개체 선택 규칙 |
| Domain/Settings | 설정 데이터·인증 결과 데이터 |
| Domain/AnimalHistory | 이력 결과 데이터 |

| Application/AnimalHistory | 이력 조회·재사용·문구 정책 |
| Application/Abstractions | 외부 조회·접속·저장·로그 계약 |
| Application/Messaging | 앱 내부 메시지 |
| Infra/Api | HTTP·외부 응답 파싱·조회 구현 |
| Infra/Netty | 소켓 연결·프로토콜·핸들러 |
| Infra/Synchronization | PC 간 페이지 동기화 |
| Infra/Persistence | SQLite·캐시 저장 |
| Infra/XmlSettings | XML 설정 읽기 |
| Infra/Logging | 로그 구현 |
| Presentation/Display | WPF 화면 선택·보드·패널 수명·페이지 표시 |
| Presentation/Converters | WPF 값 변환 |
| Presentation/Assets | 정적 로고 선택·로딩 |
| Presentation/Animation | 텍스트 스크롤 지원 |
| ViewModels | 바인딩·Command·화면 상태 연결 |
| Views | 기존 해상도·사업장별 XAML 및 공통 컨트롤 |
| App.xaml.cs | 서비스 조립·WPF 앱 시작·종료·재시작 |
| Validation | 운영 연결 없이 실행할 수 있는 검증과 별도 라이브 검사 |
| Tools/GAMSTest | 독립 전광판 점검 UI·가상 데이터·표시 설정 가져오기 |

Domain의 규칙은 WPF나 외부 저장소를 직접 사용하지 않는다. Application은 필요한 외부 동작을 계약으로 요청하고 Infra가 구현한다. App이 구현을 연결한다. PC 동기화의 UI 전달은 호출자가 제공하는 dispatch 함수를 사용한다.

화면이나 사업장 표시를 수정할 때는 기존 Views 경로를 그대로 사용한다. 계층 분리를 위해 `gValues`의 기존 프로퍼티·저장 형식을 전면 교체하지 않는다. GIF는 지원하지 않으며 정적 로고 로더에서 직접 지정과 위장 파일을 차단한다.

## 검증 안내

- [경매·표시 오프라인 검증](../Validation/ReferenceAdoptionChecks/README.md)
- [이력 검증의 안전한 실행 범위](../Validation/OwnerHistoryChecks/README.md)

최종 명령·결과와 현장 확인이 필요한 범위는 WORKLOG에 기록한다. 빌드 성공과 숨겨진 WPF 컨트롤 검사는 운영 서버·전광판·다중 PC 동기화 성공을 의미하지 않는다.
