# 시나리오 로그 검증 (2026-02-14)

## 1) ESC 종료 후 즉시 재실행

### 실행 방법
1. 앱 실행
2. 종료 신호(`CloseMainWindow`, 실제 운영에서는 `ESC`) 전달
3. 1초 내 재실행
4. 로그 확인

### 확인 로그 파일
- `bin/Debug/net9.0-windows/Logs/2026-02-14/2026-02-14.log`

### 관찰 결과
- `2026-02-14 23:33:24` 접속 결과: `AR|...|2000`
- `2026-02-14 23:33:28` 종료 시작: `Application exiting. Start cleanup.`
- `2026-02-14 23:33:29` `OnExit: ServerGetData disposed.`
- `2026-02-14 23:33:44` `OnExit: Netty client disposed.`
- `2026-02-14 23:33:44` `Application exited.`
- `AR|...|2002`는 해당 구간에서 미검출

### 판정
- 중복접속(2002) 재현 없음 (PASS)
- 종료 정리 로그는 정상 출력 (PASS)
- 단, Netty 정리 완료까지 약 16초 소요

---

## 2) 네트워크 단절 후 복구

### 현재 상태
- 본 작업 환경에서는 NIC on/off 또는 물리 단절을 자동 재현하기 어려움.
- 따라서 이 시나리오는 운영 PC에서 수동 검증 필요.

### 수동 검증 절차
1. 앱 실행 후 정상 접속 확인 (`AR|...|2000`)
2. 네트워크 단절(랜선 분리 또는 어댑터 비활성화)
3. 10~20초 유지 후 복구
4. 아래 조건 확인

### 통과 조건
1. 로그에 `NotImplementedException` 미발생
2. 연결 예외 발생 시 크래시 없이 계속 동작
3. 복구 후 `AR|...|2000` 재수신
4. `AR|...|2002`가 루프로 반복되지 않음

### 점검용 검색 명령
```powershell
rg -n "AR\\|.*\\|(2000|2002)\\|\\||Application exiting\\. Start cleanup\\.|OnExit: ServerGetData disposed\\.|OnExit: Netty client disposed\\.|응찰서버 연결 예외|NotImplementedException" -S "bin/Debug/net9.0-windows/Logs/2026-02-14/2026-02-14.log"
```
