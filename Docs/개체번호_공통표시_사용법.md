# 개체번호 공통 표시

2026-09-22 구현. [EntityNumberText](../Views/Common/EntityNumberText.cs)는 하나의 TextBlock 안에 Run 3개를 두고 개체번호를 이어서 표시한다. 가운데 강조를 위해 별도 TextBlock을 겹치거나 축약 번호를 모델에 저장하지 않는다.

## 전체 번호와 중간 강조

```xml
xmlns:entity="clr-namespace:CowAuctionSmall.Views.Common"
```

```xml
<entity:EntityNumberText
    Number="{Binding EntityNumber}"
    Foreground="{DynamicResource EntityNumberForeground}"
    HighlightForeground="{DynamicResource EntityNumberShortForeground}"
    HighlightFontWeight="Bold"
    FontSize="13" />
```

`1234 5678 9`를 `1234 `, `5678`, ` 9` 세 부분으로 표시하며, 강조 색상·굵기는 가운데 `5678`에만 적용된다. 가운데 번호의 별도 배경색 기능은 제거했다. 글자 크기는 기본 TextBlock의 `FontSize`를 사용한다. 각 부분은 같은 텍스트 흐름에 있으므로 강조 위치를 Margin이나 Canvas.Left로 따로 맞추지 않는다.

| 속성 | 역할 |
| --- | --- |
| `Number` | 전체 개체번호. 화면에서는 `EntityNumber`에 바인딩 |
| `DisplayMode` | 기본값 `Full`, 축약 표시만 필요하면 `Short` |
| `CowDistinction` | 축약 표시 시 축종 판정. `5`이면 염소의 마지막 3자리 |
| `Foreground` | 기본 글자 색상 |
| `HighlightForeground` | 강조 부분의 색상. 지정하지 않으면 기본 글자 색상 상속 |
| `HighlightFontWeight` | 강조 부분의 굵기. 지정하지 않으면 기본 굵기 상속 |
| `FontSize`, `FontFamily`, `FontWeight` | 기존 TextBlock과 같은 기본 글꼴 속성 |

기존 화면에 암시적인 `Style TargetType="TextBlock"`이 있으면 새 컨트롤에도 `Style="{StaticResource {x:Type TextBlock}}"`로 연결한다. 이번 전환에서는 해당 스타일이 있는 화면에만 연결하여 기존 글꼴·텍스트 렌더링 설정을 유지했다.

## 축약 번호만 표시

```xml
<entity:EntityNumberText
    Number="{Binding EntityNumber}"
    CowDistinction="{Binding CowDistinction}"
    DisplayMode="Short"
    Foreground="{DynamicResource EntityNumberShortForeground}"
    FontWeight="Bold" />
```

전체 번호가 `1234 5678 9`이면 소 등 기존 일반 분기는 `5678`, 염소(`5`)는 `789`를 표시한다. 같은 번호라도 축종이 변경되면 다시 계산한다. 축약 표시에는 원래의 위치·정렬·굵기·색상을 유지할 수 있다.

## 입력과 갱신

- 기존 4-4-1 공백 형식, 9자리 숫자, 15자리 원문 번호를 처리한다. 15자리에서는 마지막 9자리를 표시한다.
- 공백·하이픈 구분자를 정리하며 앞자리의 0은 보존한다.
- 빈 값은 전체 표시를 비운다. 길이가 맞지 않거나 문자가 섞인 값은 임의로 잘라 강조하지 않고 받은 문자열을 그대로 표시한다.
- 번호 변경 때 기존 Run 3개를 재사용한다. 별도 타이머·이벤트 구독·작업 스레드가 없다.
- MVVM 표시 스냅샷 교체 규칙은 유지한다. 원본을 변경한 뒤 기존 갱신 진입점을 통해 전달한다.
- 인라인 텍스트 검사에서는 각 Run 또는 `TextRange(ContentStart, ContentEnd).Text`를 사용한다. 숨겨진 중첩 화면에서 레이아웃이 끝나기 전 `TextBlock.Text`의 합쳐진 값만 읽으면 인라인 내용과 다른 시점의 값을 볼 수 있다.

## 기존 설정·데이터 호환

- `gValues.EntityNumberShort`와 파서의 축약 계산, 비교·복제·캐시 저장 항목을 제거했다.
- `EntityNumberShortForeground`는 가운데 강조와 단독 축약 번호의 글자 색상에 사용한다. `EntityNumberShortBackground`는 단독 축약 번호 10곳의 TextBlock 배경에서 사용하므로 설정·리소스를 유지한다. 전체 번호의 가운데 Run에는 배경색을 지정하지 않는다.
- 구 버전 캐시에 `EntityNumberShort`가 남아 있어도 읽을 수 있다. 새 캐시는 `EntityNumber`를 저장하고 강조·축약 부분은 표시 시 계산한다.
- 어미·자축 개체번호의 별도 포맷은 이번 전환 범위에 포함하지 않는다.

## 변경 범위와 검증

- 가운데 배경 강조 제거 후 Debug 빌드 오류 0개(기존 경고 80개), `entity` 34개와 `binding` 1,497개 통과. 아래 전체·Release·캐시 검사는 최초 공통 표시 구현 당시 결과다.
- 53개 화면에 공통 컨트롤 63개 적용: 전체 표시 52개, 축약 표시 11개.
- 전체 번호 위에 축약 번호를 겹치던 TextBlock 51개 제거. 전체 번호의 기준 위치와 주변 레이아웃을 유지하고 덧씌우기용 좌표·폭은 제거했다.
- Debug 전체 검사 2,843개, Release `entity` 35개와 `binding` 1,497개 통과.
- 소유주 이력·캐시 오프라인 검사 55 + 25 = 80개 통과. 기존 캐시의 불필요한 축약 필드도 읽히는지 검증했다.
- 실제 운영 서버·전광판 실행은 하지 않았다. 사업장별 실제 해상도에서 글자 폭·주변 항목과의 간격·강조 가독성은 현장 확인 항목이다.

$entityOutput = Join-Path $env:TEMP 'CowAuction-EntityValidation-Debug'
