# 페이지 인디케이터 UI 형식 설계 (2026-02-24)

## 1. 목적
- `MASTER/SUB` 페이지 회전 상태를 로그 없이 화면에서 즉시 확인한다.
- 유전능력 페이지 고정, 동기 불일치, freeze 상태를 운영자가 빠르게 감지한다.

## 2. 배치 위치
- 기존 `MsgTextBox` 바로 아래(하단 상태영역) 배치.
- 메인 화면 하단에 고정 표시.

## 3. 레이아웃 형식
- 한 줄 상태바 형태.
- 왼쪽: 역할/상태 텍스트
- 오른쪽: 페이지 점(동그라미) 인디케이터

예시:
```text
[ROLE: MASTER] [SYNC: NORMAL]                  ● ○
```

freeze 예시:
```text
[ROLE: MASTER] [SYNC: FREEZE]                  ◉ ○
```

fallback 예시:
```text
[ROLE: SUB] [SYNC: FALLBACK]                   ○ ●
```

## 4. 점(동그라미) 규칙
- 점 개수는 `users.XML`의 `BoardPage` 값 사용.
- 허용 범위는 1~4로 제한.
- 현재 페이지만 활성 색상, 나머지는 비활성 색상.
- `BoardPage == 1`이면 점 UI 숨김.

## 5. 상태별 색상 규칙
- 기본 비활성: 회색
- 활성 페이지: 초록
- freeze 상태: 노랑(활성 페이지 노랑 강조)
- fallback 상태: 청록/하늘색(활성 페이지 색상 대체)

## 6. 상태 텍스트 규칙
- ROLE: `MASTER` 또는 `SUB`
- SYNC:
1. `NORMAL` : 일반 동기 상태
2. `FREEZE` : `_lockFirstPageUntilRefresh == true` 또는 경매진행 중 페이지 고정
3. `FALLBACK` : SUB 동기 미수신으로 로컬 회전 동작 중

## 7. 갱신 트리거
- 페이지 변경 시
- `MASTER/SUB` 전환 시
- freeze lock/unlock 시
- fallback enter/exit 시
- refresh 수신 시

## 8. 운영 관점 기대효과
- 로그 창을 열지 않아도 현재 페이지와 상태를 즉시 파악 가능.
- `MASTER는 회전 중인데 SUB가 정지` 같은 불일치를 즉시 식별 가능.
- 유전능력 페이지 고정 이슈를 시각적으로 빠르게 감지 가능.

## 9. 수용 기준(간단)
1. 페이지 수가 2면 점 2개, 3이면 점 3개로 표시된다.
2. 현재 페이지 전환 시 활성 점이 즉시 이동한다.
3. freeze 시 점 색상이 노랑으로 바뀌고, 해제 시 원복된다.
4. SUB fallback 진입/복귀 시 상태 텍스트와 점 색상이 즉시 반영된다.
