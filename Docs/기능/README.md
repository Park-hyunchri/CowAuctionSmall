## 남은 작업을 찾는 법

- 현재 코드에서 확인한 제한은 각 기능 문서의 `남은 확인`에 적는다.
- 구체적인 변경안은 [후속 계획](../README.md#후속-계획)에 연결한다. 일부 구현이 있으면 문서를 통째로 미착수로 표시하지 않는다.
- 완료한 계획은 당시 설계·검증 기록이다. 후속 변경으로 달라진 동작은 이 폴더의 기능 문서에 반영한다.
- 과거 실측은 관찰한 프로그램·시각·조건에 한정한다. MAUI 수신 검증을 현재 WPF 전광판의 실측 결과로 대체하지 않는다.
